# NVIDIA desktop display names

Offline catalogue used only by the reversible Windows display-name editor.
Changing a name does not add GPU capabilities or change a device's hardware IDs.

- NVIDIA driver supported-products table (595.45.04, including legacy tables):
  https://download.nvidia.com/XFree86/Linux-x86_64/595.45.04/README/supportedchips.html
- CMP 30HX / 40HX / 50HX / 90HX product page:
  https://www.nvidia.com/en-us/cmp/
- CMP 170HX: NVIDIA Product Description Sheet identified in US CIT 26-04:
  https://www.cit.uscourts.gov/sites/cit/files/26-04.pdf

Distinct official names are retained, including OEM and D variants. Explicit
laptop, Max-Q, mobile, embedded, server and combined chipset aliases are excluded.
Mobile-only workstation names without a mobile suffix are excluded separately.
Shared desktop/mobile marketing names refer to their desktop variant here.
The first two entries retain the historical 4060 / 5090 command compatibility.
The picker is searchable; names never come from an arbitrary registry path.
